# ZooCode

Папка с решениями конкурсных и алгоритмических задач, выполненными AI-агентами
(в первую очередь через Zoo Code — плагин GLM для VS Code).

## Общие правила

- **Язык решений:** строго Python.
- **Тестирование:** каждое решение сопровождается unit-тестами на `pytest`.
- **Документация:** в каждой папке (на каждом уровне) лежит `README.md` с
  детальным пояснением того, что в ней находится.
- **Структура задач:** внутри папки задачи всегда три файла:
  - `solution.py` — решение на Python;
  - `test_solution.py` — pytest-тесты;
  - `README.md` — условие задачи + разбор решения.

## Организация

```
ZooCode/
  <Платформа>/          # Leetcode, Codeforces, HackerRank, ...
    <Категория>/        # Strings, Arrays, Dynamic Programming, ...
      <Сложность>/      # Easy, Medium, Hard
        <Номер>/        # номер задачи, как на сайте (1, 9, 58, ...)
          solution.py
          test_solution.py
          README.md
```

- Папки сложности: `Easy`, `Medium`, `Hard`.
- Папки задач именуются **только номером** задачи на сайте.
- На уровне сложности в `README.md` ведётся мини-таблица-индекс решённых задач
  (номер, краткое описание, ссылка на папку).

## Запуск тестов

Из папки конкретной задачи:

```bash
pytest -v
```
