# LeetCode

Решения задач с [leetcode.com](https://leetcode.com).

## Структура

Задачи группируются по категориям (тематическим спискам LeetCode),
а внутри категории — по сложности.

```
Leetcode/
  <Категория>/        # Strings, Arrays, ...
    Easy/
    Medium/
    Hard/
```

Каждая папка сложности содержит папки с номерами задач, а внутри —
стандартный набор: `solution.py`, `test_solution.py`, `README.md`
(см. общий [`ZooCode/README.md`](../README.md)).

## Категории

| Категория  | Описание                                      | Папка            |
|------------|-----------------------------------------------|------------------|
| Strings    | Задачи на работу со строками                  | [Strings/](Strings/) |

> По мере добавления новых категорий дополняйте таблицу выше.
