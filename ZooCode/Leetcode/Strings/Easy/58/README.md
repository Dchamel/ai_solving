# 58. Length of Last Word (Easy)

> [LeetCode 58](https://leetcode.com/problems/length-of-last-word/)

## Условение

Дана строка `s`, состоящая из слов и пробелов. Вернуть длину последнего слова.

Слово — максимальная подстрока, состоящая только из непробельных символов.

**Примеры:**
- `s = "Hello World"` → `5`
- `s = "   fly me   to   the moon  "` → `4`
- `s = "luffy is still joyboy"` → `6`

**Ограничения:** `1 <= s.length <= 10^4`, `s` состоит из английских букв и пробелов,
в `s` есть хотя бы одно слово.

## Решение

**Сканирование справа.** Сначала пропускаем trailing-пробелы, затем считаем
символы до следующего пробела (или начала строки). Это длина последнего слова.

### Сложность
- **Время:** O(n) — один проход справа.
- **Память:** O(1).
