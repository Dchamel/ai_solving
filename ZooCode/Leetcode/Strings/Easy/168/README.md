# 168. Excel Sheet Column Title (Easy)

> [LeetCode 168](https://leetcode.com/problems/excel-sheet-column-title/)

## Условение

Дано целое число `columnNumber`. Вернуть соответствующее название колонки
Excel.

| Число | Колонка |
|-------|---------|
| 1     | A       |
| 28    | AB      |
| 701   | ZY      |
| 2147483647 | FXSHRXW |

**Ограничения:** `1 <= columnNumber <= 2^31 - 1`.

## Решение

**Система счисления по основанию 26 без нуля.** В отличие от обычной
позиционной системы, здесь цифры — `A..Z` (1..26), а нуля нет. Поэтому на
каждой итерации вычитаем 1: это сдвигает диапазон `1..26` в `0..25`, после
чего остаток `n % 26` даёт индекс буквы, а `n //= 26` — следующий разряд.

### Сложность
- **Время:** O(log₂₆ n) — количество разрядов.
- **Память:** O(log₂₆ n) для результата.
