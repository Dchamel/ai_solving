# 242. Valid Anagram (Easy)

> [LeetCode 242](https://leetcode.com/problems/valid-anagram/)

## Условение

Даны строки `s` и `t`. Вернуть `true`, если `t` — анаграмма `s`, иначе `false`.

Анаграмма — перестановка букв: строки содержат одни и те же символы в тех же
количествах.

**Примеры:**
- `s = "anagram", t = "nagaram"` → `true`
- `s = "rat", t = "car"` → `false`

**Ограничения:** `1 <= s.length, t.length <= 5*10^4`, строчные английские буквы.

## Решение

**Подсчёт частот.** Если длины различны — сразу `false`. Считаем частоты
символов `s` в словаре, затем для каждого символа `t` уменьшаем счётчик.
Если символ отсутствует или счётчик уходит в минус — не анаграмма.

### Сложность
- **Время:** O(n).
- **Память:** O(k), k — размер алфавита (≤ 26).
