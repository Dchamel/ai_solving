# 13. Roman to Integer (Easy)

> [LeetCode 13](https://leetcode.com/problems/roman-to-integer/)

## Условие

Дана строка `s`, представляющая римское число. Преобразовать её в целое число.

Римские цифры: `I=1, V=5, X=10, L=50, C=100, D=500, M=1000`.

Обычно меньшее значение ставится справа от большего и прибавляется. Но есть
шесть вычитательных пар, где меньшее стоит слева от большего:

| Пара | Значение |
|------|----------|
| IV   | 4        |
| IX   | 9        |
| XL   | 40       |
| XC   | 90       |
| CD   | 400      |
| CM   | 900      |

**Примеры:**
- `s = "III"` → `3`
- `s = "LVIII"` → `58` (50 + 5 + 3)
- `s = "MCMXCIV"` → `1994` (1000 + 900 + 90 + 4)

**Ограничения:** `1 <= s.length <= 15`, `s` содержит только `IVXLCDM`,
гарантированно валидное римское число в диапазоне `[1, 3999]`.

## Решение

Проходим строку справа налево. Для каждого символа сравниваем его значение с
предыдущим (правым соседом):

- если текущее **меньше** предыдущего — это вычитательная пара, вычитаем;
- иначе — прибавляем.

### Сложность
- **Время:** O(n) — один проход по строке.
- **Память:** O(1) — фиксированная таблица значений.
