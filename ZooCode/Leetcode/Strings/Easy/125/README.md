# 125. Valid Palindrome (Easy)

> [LeetCode 125](https://leetcode.com/problems/valid-palindrome/)

## Условение

Фраза является палиндромом, если после перевода всех заглавных букв в
строчные и удаления всех не-алфавитно-цифровых символов она читается
одинаково слева направо и справа налево. Вернуть `true`, если фраза —
палиндром.

**Примеры:**
- `s = "A man, a plan, a canal: Panama"` → `true`
- `s = "race a car"` → `false`
- `s = " "` → `true`

**Ограничения:** `1 <= s.length <= 2*10^5`, `s` состоит из печатаемых ASCII.

## Решение

**Два указателя.** Левый и правый указатели двигаются навстречу, пропуская
не-алфавитно-цифровые символы. Сравниваем символы в нижнем регистре.

### Сложность
- **Время:** O(n) — один проход.
- **Память:** O(1).
