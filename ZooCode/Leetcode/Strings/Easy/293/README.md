# 293. Flip Game (Easy)

> [LeetCode 293](https://leetcode.com/problems/flip-game/)

## Условение

Игра со строкой из символов `+` и `-`. За один ход можно перевернуть два
последовательных `++` в `--`. Вернуть все возможные состояния строки после
одного валидного хода.

**Примеры:**
- `s = "++++"` → `["--++", "+--+", "++--"]`
- `s = "--"` → `[]`

**Ограничения:** `s` содержит только `+` и `-`.

## Решение

**Линейный поиск.** Проходим строку, для каждой пары `++` создаём копию с
`--` на этой позиции и добавляем в результат.

### Сложность
- **Время:** O(n²) — до O(n) ходов, каждый создаёт строку O(n).
- **Память:** O(n²) для результата.
