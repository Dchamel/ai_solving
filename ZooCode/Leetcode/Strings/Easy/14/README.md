# 14. Longest Common Prefix (Easy)

> [LeetCode 14](https://leetcode.com/problems/longest-common-prefix/)

## Условие

Дан массив строк `strs`. Найти самый длинный общий префикс среди всех строк.
Если общего префикса нет — вернуть `""`.

**Примеры:**
- `strs = ["flower","flow","flight"]` → `"fl"`
- `strs = ["dog","racecar","car"]` → `""`

**Ограничения:** `1 <= strs.length <= 200`, `0 <= strs[i].length <= 200`,
`strs[i]` содержит только строчные английские буквы.

## Решение

**Вертикальное сканирование.** Берём первую строку как эталон и для каждой
позиции `i` проверяем, что символ `strs[0][i]` совпадает с символом на той же
позиции во всех остальных строках. При первом несовпадении (или выходе за
длину строки) возвращаем префикс `strs[0][:i]`.

### Сложность
- **Время:** O(S), где S — суммарная длина всех строк (в худшем случае
  проверяем все символы).
- **Память:** O(1) дополнительно (результат — срез первой строки).
