# 266. Palindrome Permutation (Easy)

> [LeetCode 266](https://leetcode.com/problems/palindrome-permutation/)

## Условение

Дана строка `s`. Вернуть `true`, если какая-либо перестановка строки может
образовать палиндром.

**Примеры:**
- `s = "code"` → `false`
- `s = "aab"` → `true` (`"aba"`)
- `s = "carerac"` → `true` (`"racecar"`)

**Ограничения:** строка состоит только из строчных английских букв.

## Решение

**Чётность частот.** Строку можно переставить в палиндром тогда и только
тогда, когда **не более одного** символа имеет нечётную частоту.

Используем множество как «счётчик по модулю 2»: добавляем символ, если его
нет; удаляем, если есть. В конце в множестве остаются символы с нечётной
частотой. Если их ≤ 1 — палиндром возможен.

### Сложность
- **Время:** O(n).
- **Память:** O(k), k — размер алфавита.
