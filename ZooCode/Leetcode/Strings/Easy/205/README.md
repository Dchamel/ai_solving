# 205. Isomorphic Strings (Easy)

> [LeetCode 205](https://leetcode.com/problems/isomorphic-strings/)

## Условение

Две строки `s` и `t` изоморфны, если символы в `s` можно заменить, чтобы
получить `t`. Сохранение порядка символов, никакие два символа не могут
отображаться в один и тот же символ, но символ может отображаться в себя.

**Примеры:**
- `s = "egg", t = "add"` → `true` (e→a, g→d)
- `s = "foo", t = "bar"` → `false` (f→b, o→a, но второй o→r ≠ a)
- `s = "paper", t = "title"` → `true`

**Ограничения:** `s.length == t.length`, `1 <= s.length <= 5*10^4`.

## Решение

**Два словаря (биекция).** Строим отображение `s→t` и `t→s` одновременно.
Если для очередного символа отображение уже определено и не совпадает с
текущей парой — строки не изоморфны. Два словаря гарантируют инъективность
в обе стороны (биекцию).

### Сложность
- **Время:** O(n).
- **Память:** O(k), k — размер алфавита (≤ n).
