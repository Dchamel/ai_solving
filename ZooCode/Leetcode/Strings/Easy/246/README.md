# 246. Strobogrammatic Number (Easy)

> [LeetCode 246](https://leetcode.com/problems/strobogrammatic-number/)

## Условение

Стробограмматическое число — число, которое выглядит одинаково при повороте на
180° (вверх ногами). Вернуть `true`, если строка `num` — стробограмматическое
число.

Валидные отображения цифр при повороте: `0→0, 1→1, 6→9, 8→8, 9→6`.
Цифры `2, 3, 4, 5, 7` не валидны.

**Примеры:**
- `num = "69"` → `true`
- `num = "88"` → `true`
- `num = "962"` → `false`

**Ограничения:** `1 <= num.length <= 50`, `num` состоит только из цифр.

## Решение

**Два указателя.** Слева и справа двигаемся к центру. Для каждой пары
символов проверяем, что левый — валидная цифра и его поворот равен правому.

### Сложность
- **Время:** O(n).
- **Память:** O(1).
