# 67. Add Binary (Easy)

> [LeetCode 67](https://leetcode.com/problems/add-binary/)

## Условение

Даны две бинарные строки `a` и `b`. Вернуть их сумму как бинарную строку.

**Примеры:**
- `a = "11", b = "1"` → `"100"`
- `a = "1010", b = "1011"` → `"10101"`

**Ограничения:** `1 <= a.length, b.length <= 10^4`, строки содержат только
`'0'` и `'1'`, без ведущих нулей (кроме самого нуля).

## Решение

**Сложение столбиком справа налево.** Двигаем два указателя с конца строк,
поддерживаем перенос `carry`. На каждом шаге суммируем биты с переносом,
записываем `total % 2` в результат, переносим `total // 2`.

### Сложность
- **Время:** O(max(n, m)).
- **Память:** O(max(n, m)) для результата.
