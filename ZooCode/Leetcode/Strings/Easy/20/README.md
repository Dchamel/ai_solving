# 20. Valid Parentheses (Easy)

> [LeetCode 20](https://leetcode.com/problems/valid-parentheses/)

## Условие

Дана строка `s`, содержащая только символы `'('`, `')'`, `'{'`, `'}'`, `'['`,
`']'`. Определить, является ли строка валидной.

Строка валидна, если:
1. Открытые скобки закрыты скобками того же типа.
2. Открытые скобки закрыты в правильном порядке.
3. Каждой закрывающей скобке соответствует открывающая.

**Примеры:**
- `s = "()"` → `true`
- `s = "()[]{}"` → `true`
- `s = "(]"` → `false`

**Ограничения:** `1 <= s.length <= 10^4`, `s` состоит только из скобок.

## Решение

**Стек.** Проходим строку слева направо:

- открывающую скобку → кладём в стек;
- закрывающую скобку → проверяем, что стек не пуст и вершина стека —
  соответствующая открывающая; если да — снимаем её, иначе — невалидно.

В конце стек должен быть пуст.

### Сложность
- **Время:** O(n) — один проход.
- **Память:** O(n) — стек в худшем случае (все открывающие).
