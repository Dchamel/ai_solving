# 257. Binary Tree Paths (Easy)

> [LeetCode 257](https://leetcode.com/problems/binary-tree-paths/)

## Условение

Дан корень бинарного дерева. Вернуть все пути от корня до листьев в любом
порядке, каждый в виде строки `"1->2->3"`.

**Пример:**
```
    1
   / \
  2   3
   \
    5
```
→ `["1->2->5","1->3"]`

**Ограничения:** число узлов `[1, 100]`, `-100 <= Node.val <= 100`.

## Решение

**DFS с накоплением пути.** Рекурсивно обходим дерево, поддерживая текущий
путь строкой. В листе добавляем путь в результат.

### Сложность
- **Время:** O(n) — каждый узел посещается один раз (построение строки
  амортизированно).
- **Память:** O(h) для стека рекурсии, h — высота дерева.
